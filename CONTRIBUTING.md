# Contributing to Sprout

Thanks for your interest! Sprout is a design-forward demo site for a concept
wellness/habit app, built with Astro.

## Setup

```bash
npm install
npm run dev
```

## Before opening a PR

```bash
npm run format
npm run lint
npm run typecheck
npm run test
npm run build
```

## Guidelines

- Keep every page readable without JavaScript (progressive enhancement).
- Respect `prefers-reduced-motion` for the floating phone and reveals.
- Hold the soft pastel palette; leaf green leads, peach/lilac/sky support.
- Keep display type on Fraunces and body on Nunito.

Sprout is a design concept, not a shipping app.
